# 安全说明

## 密钥

- `api_key`：每轮模型请求都要带，只发给信任的人
- `admin_key`：监控 / 日志 / 清理接口的钥匙，**绝对不要外发**
- 首次运行自动生成，存在 `gateway_config.json`
- 要换密钥：改文件、重启程序

## 网络暴露面

- 网关只监听 `127.0.0.1`
- 公网入口只有隧道，且按需创建
- 默认 Cloudflare 临时隧道地址随机；要固定地址用自己的域名 + 命名隧道

## 日志是隐私数据

`logs/conversations-*.jsonl` 里有完整提示词和回复。这是"主控端"的设计使然，但：

- 不要把 `logs/` 提交到仓库
- 用监控页的筛选清理论文（删前会自动备份到 `logs/archive/`）
- 把这台机器当成存放别人隐私的机器

## 资源安全

- 空闲 `idle_unload_seconds`（默认 60 秒）后自动卸载模型，省显存省电
- 同一来源的请求串行处理，避免抢显存；忙时返回 HTTP 429 + `code: "busy"`
