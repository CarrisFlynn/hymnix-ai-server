# 上架微软应用商店（路线图）

可以上架，但要先做几处架构调整。

## 商店的要求

| 要求 | 现状 | 要做 |
|---|---|---|
| MSIX 安装包 | 还没有 | 加 `build-msix.ps1`（MSIX Packaging Tool / Desktop Bridge） |
| 不能往 exe 同目录写数据 | 现在配置/日志写在 exe 旁 | 数据目录改到 `%LOCALAPPDATA%\\Hymnix`（必须先做） |
| 不需要管理员权限 | 已满足 | 保持 |
| 开发者账号 | — | 一次性注册费约 $19 |
| 隐私政策链接 | — | 写一份（日志只存本机） |
| 年龄分级 / 商店素材 | — | 中英文截图、简介、分类（开发工具/实用工具） |
| 第三方二进制 | 打包了 `cloudflared.exe`（约 55MB） | 首次运行下载，或随包附带许可证 |
| AGPL-3.0 | 源码公开 | 商店页面必须链接源码（AGPL 兼容） |

## 审核风险点

- **联网/隧道**：程序会开隧道把本机服务暴露出去。工具本身合法，但审核可能问用途，要写清楚"本地 AI 服务器 + 给受邀用户的可选公网入口"
- **内置隧道二进制**：第三方程序，要么带许可证，要么运行时从官方下载
- **数据位置**：商店应用不能写安装目录，现在的"写在 exe 旁边"会被拦

## 建议顺序

1. 先完成 GitHub 开源发布（已完成）
2. 数据目录迁到 `%LOCALAPPDATA%\\Hymnix`
3. 写 `docs/PRIVACY.md`（存什么、存哪、不出本机）
4. 加 MSIX 打包脚本和清单（capabilities 只留 `internetClient`）
5. 提交 Partner Center
