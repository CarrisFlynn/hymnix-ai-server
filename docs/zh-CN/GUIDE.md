# 操作指南

日常使用 Hymnix 的分步说明。每一步都写清了点哪个按钮、填哪个字段。

## 1. 第一次运行

1. 安装 Ollama：`winget install Ollama.Ollama`（或从 ollama.com 下载）。
2. 拉模型：`ollama pull qwen3:8b`。
3. 双击 **Hymnix-AI-Server.exe**。
4. 等状态栏的 **网关**、**模型** 圆点变绿。
5. 配置目录会自动创建在 `%LOCALAPPDATA%\Hymnix\`，可通过 **文件 -> 打开数据目录** 打开。

## 2. 启动公网隧道

隧道是**手动**申请的——每开一次都会占用一个公网地址。

1. 点状态栏的 **启动隧道**。
2. 第一次会自动下载 cloudflared（约 55MB）。
3. 地址出现后（类似 `https://random-words.trycloudflare.com`），点 **复制地址**。
4. 剪贴板里是 **地址 + API Key**，可直接发给朋友。

不想分享时点 **停止隧道**，地址立即失效。

## 3. 邀请朋友

发给他两样东西：

1. **Hymnix-Client.exe**
2. 刚才复制的那段文字（地址 + 密钥）

他打开 **设置 -> AI 接口** 填：

| 字段 | 填什么 |
|---|---|
| 接口地址 | 复制的地址 + `/v1` |
| API Key | 复制的密钥 |
| 模型 | `qwen3:8b` |

然后 **测试连接** -> **保存**。

## 4. 查看请求

切到 **服务端监控** 标签页：

- 左列：已连接客户端（IP、请求数、最近活跃）
- 右表：每条请求一行（时间、来源、模型、耗时），点一行看完整提示词、思考、工具调用、回复、能耗
- 筛选：时间范围、来源 IP、关键词

## 5. 清理日志

日志包含完整对话，用筛选清理：

1. 点 **清理历史…**
2. 选日期范围、IP、关键词（至少给一个条件）
3. **预览** 显示匹配多少条
4. **执行清理** 会先归档到 `logs/archive/` 再从列表移除

归档文件夹你自己不删，数据就一直还在。

## 6. 切换模型

- 左侧 **模型** 下拉列出已安装模型
- **刷新模型** 重新扫描 Ollama
- **下载模型** 打开模型货架（搜索、体积、显存要求）
- 计算设备条上点 **应用** 可绑定 GPU 或强制 CPU

模型在空闲 60 秒后自动从显存卸载（可用 `idle_unload_seconds` 调整）。

## 7. 改端口 / 密钥

编辑 `%LOCALAPPDATA%\Hymnix\gateway_config.json` 后重启：

- `listen_port` 网关端口
- `api_key` 朋友用的密钥
- `admin_key` 你的监控/管理密钥，**绝不外发**
- `model_aliases` 把客户端传来的模型名映射到真实模型
- `compat_mode` auto / openai / text_tools / plain / json_only

## 8. 常用操作

| 想做什么 | 怎么做 |
|---|---|
| 看谁连着 | 服务端监控 -> 左列 |
| 查公网地址 | 状态栏 |
| 马上停止分享 | 停止隧道 |
| 立刻释放显存 | 等 60 秒，或重启程序 |
| 开关界面音效 | 插件页 -> 界面音效 |
| 打开数据目录 | 文件 -> 打开数据目录 |
