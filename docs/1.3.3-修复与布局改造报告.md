## 一、P0：安全

### 1. 管理接口可被匿名接管（完整链路）

| 修复 | 位置 |
|---|---|
| `_dispatch` 在路由前统一校验 `/admin/*`，今后新增管理路由不可能漏掉鉴权 | `server/gateway_core.py` |
| `/admin/network` 不再明文返回共享密码；只有「本机直连 + 已通过管理密钥」才返回，`CF-Connecting-IP`/`CF-Ray` 等隧道标记一律不返回 | 同上 |
| `/connect` 失败计入同一封禁列表（10 分钟内 8 次即封），密码先比对再校验名字 | 同上 |
| 默认管理密钥从 `token_hex(6)`（48 bit）提升到 `token_hex(18)`（144 bit） | `_ensure_keys` |

验证（真实起网关打 27 条断言）：无密钥访问 7 个管理端点全部 401；带密钥 `host_password` 为空、`?reveal=1` 才有值；带 `CF-Connecting-IP` 时即使 reveal 也拿不到。

### 2. CORS `*` + DNS rebinding

`_json`、`do_OPTIONS` 和流式响应都改为 Origin 白名单（`app://hymnix`、`http://localhost|127.0.0.1[:port]`），并加 `Vary: Origin`。非白名单来源不返回任何 CORS 头。

### 3. 其它安全项

- **SSRF**：云端 `base_url` 校验协议与管理，拒绝链路本地（169.254.0.0/16，即云元数据）、未指定、保留、组播地址；本机与内网地址保留（OpenClaw 与本机 provider 是合法用法）。
- **普通密钥越权**：`_proxy` 拦截 `/api/pull|push|delete|create|copy|blobs`，访客密钥无法拉取或删除模型。
- **终端 RCE 面**（`shell: true`）：改为固定 shell（`%ComSpec%` 或 `/bin/sh`）+ 参数数组、`windowsVerbatimArguments`；cwd 强制收进已选工作区；取消与退出时用 `taskkill /t /f` 结束整棵进程树（`before-quit` 新增 `stopAllTerminals()`）。
- **管理面板密钥**：`dashboard.html` 不再写 `localStorage`，只留在页面内存。
- **符号链接逃逸**：`files:search` 补上 `realpath + relative` 越界判断（`files:tree` 早就有了）。
- **自定义协议路径**：`app://` 处理器改用 `relative()` 判断越界，不再用前缀字符串比较（原先同前缀兄弟目录可穿越）。
- **CSP**：显式声明 `font-src/media-src/object-src/frame-src/worker-src`。

### 4. 插件沙箱

- 拦截危险双下划线属性（`__class__`/`__subclasses__`/`__globals__` 等），堵住审阅报告里的逃逸链。
- 用 `sys.settrace` 截止时间在**插件代码内部**抛异常，超时真的会中断执行，而不是只放弃等待（线程无法被外部杀死，这是唯一可行方式）。实测 0.2s 截止在 0.20s 内中断死循环。

## 三、主题、图形与布局

### 3.1 破坏渲染的 P0

- **柔化强调色自引用变量**：`--accent-fill: color-mix(var(--accent-fill)…)` 在计算值阶段无效，主按钮/开关/勾选/徽标/进度条背景全部透明。改为从主题新增的 `--accent-fill-base` 派生，并且**向文字色去饱和**而不是向 surface 混合——后者在亮色主题会把填充提亮到 3.37:1。
- **首屏闪白**：主题引导从 `type="module"`（延迟执行）改成 `<head>` 内阻塞式经典脚本（放 `public/` 才会被 Vite 原样拷贝）；同一脚本顺带在第一帧前写好 density / text-scale / reduce-motion / soften-accent；主进程窗口底色改用上次解析出的 `--bg`（存进 settings）。
- **Auto 模式不可恢复**：设置页补回「浅色 / 深色 / 自动」分段控件；选择另一模式的主题仍显式生效。

### 3.2 对比度（九套主题全部 AA）

| 问题 | 修复 |
|---|---|
| 关闭按钮 `color: white` 在 5 个暗色主题 2.78:1 | 改 `var(--surface)`（亮/暗向都 ≥ 5.9:1） |
| 终端 SYS/ERR 标签在 4 个浅色主题 3.0–3.5:1 | 新增 `--term-success/-warning/-error` 并按明暗主题取值 |
| tonal 按钮 hover 在 4 个主题跌破 4.5:1 | hover 时文字改 `var(--text)` |
| 错误面板图标 `on-accent` 在 ROG 2.78:1 | 改 `var(--surface)` |
| 禁用按钮 0.48 透明度几乎看不见 | 提到 0.58 |

### 3.3 布局（可见的改造）

- **对话检查器**：<1280px 从「浮层压住输入框和最后回复」改为抽屉，并让主列让出等宽（`--inspect-drawer`），不再遮挡。
- **侧边栏图标栏**：<1023px 原先靠 `font-size: 0` 隐藏文字，结果中文标签竖排换行；现在直接隐藏文本节点，是干净的图标栏。
- **输入框上下文胶囊**：模型（带状态点）与推理强度显示在输入框里，点击打开检查器；窄屏自动隐藏。
- **页头操作区**：`.header-actions` 恢复为右对齐的 flex 聚合，监控页「自动刷新」不再竖排。
- **外观设置**：外观模式分段控件 + 九张主题卡（真实配色预览）。
- **字体**：统一 Windows 原生文字字体；删除不可达的 Inter 与重复字重（约 240 KB 死负载），mono 保留 JetBrains Mono 单字重（浏览器合成粗体）。
- **断点**：两段永不触发的 680px 媒体查询改到可达的 860px。
- **Tooltip**：水平夹取到视口内，右缘按钮的提示不再被裁掉。
