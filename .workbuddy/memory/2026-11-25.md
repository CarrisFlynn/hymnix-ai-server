## Hymnix Orbit 1.3.3 — UI 收尾（第三轮反馈）

- 删除页面：Files、Tools、Approvals、Logs（日志页）整页移除；日志只保留 Changelog（更新日志）。
- 主导航：对话 / 模型 / 共享与连接 / 插件 / 更新日志 / 赞助 + 开发者组（监控、终端，不再折叠）。
- 帮助菜单删除：更新日志与赞助进主导航，快捷键留在设置。
- 每个页面标题左侧有返回按钮（`navTrailRef` 历史栈 + Alt+←），返回上一页。
- 主题卡片改为全局唯一选中：`selected = theme === preset.id`，不再亮/暗各勾一个。
- 文字大小真正缩放：orbit-v2.css / styles.css 所有 `font-size: Npx` → `calc(Npx * var(--text-scale,1))`，semantic.css 的 `--fs-*` 同样处理；范围 90–150%。
- 设置：启动与运行只留 3 个开关；缓存目录固定为 `<userData>\Cache`（Electron 默认 cache 落在 roaming 根目录），新增 `system:paths` / `shell:reveal` IPC 显示真实路径并提供打开文件夹；「预览时使用的方式」改名「文件预览」。
- 测试：protocol.test.mjs 断言上述页面保持删除、返回按钮存在、导航项；视觉基线 11 页 × 9 主题 = 99 张。
